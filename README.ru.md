## Возможности

Показания сети, нагрузки, солнца и батареи сохраняют различие между нулём и отсутствием данных. Шесть режимов ESS, флаги контроллера, Water и setpoint доступны только при актуальном состоянии и разрешающей возможности сервера. Список Home берётся из конфигурации; неактивная техника скрывается. Active Loads, графики и предупреждения следуют общим правилам Desktop.

## Установка для разработки

Используйте версию Node из текущего CI и зависимости из lockfile. Vite обычно запускается на порту 5173. Для данных нужны сервер и маршруты `/api/*` и `/ws` с того же origin; один Vite не подключает инвертор. Для готового развёртывания используйте инструкции Python или Go.

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm run lint
npm test
npm run build:all
```

## Настройки и языки

В Settings выбираются язык, видимость секций, тарифы и уведомления. Поддерживаются English, Русский, Українська, Deutsch, Français и Nederlands. Явный выбор приоритетнее языка браузера; резервный язык — английский. Имена устройств, заданные владельцем, не переводятся. Данные подключения и токены хранятся на сервере.

## Предупреждения и история

Возраст баннера считается от времени события, а не получения после переподключения. Неизвестное время не превращается в «только что». График оставляет разрывы при отсутствии данных; буфер сессии ограничен 1800 точками и не является постоянным архивом за сутки. Системные уведомления требуют разрешения браузера и Web Push на сервере. Успешная постановка теста в очередь не подтверждает появление баннера ОС.

## Развёртывание и безопасность

Выход сборки — `dist/` для приложения и `dist-lib/` для библиотеки компонентов. Изменение интерфейса появляется в установленных серверах только после включения проверенного пакета и обновления серверной сборки. Desktop имеет собственный исходный код и нативные функции. Личные Home-сущности держите в исключённых из Git настройках. Не помещайте IGW/Cloudflare-токены в `VITE_*` и не отключайте TLS.

```sh
VITE_PUBLIC_MODE=true npm run build:spa
```

## Если что-то не работает

Страница недоступна: проверьте DNS, VPN, TLS и ingress. Данные устарели: отдельно проверьте браузер → сервер → IGW → Cerbo. Кнопка заблокирована: проверьте состояние, актуальность и возможности источника, не удаляя защиту. Нет системного баннера: проверяйте подписку и фактическую доставку отдельно.
